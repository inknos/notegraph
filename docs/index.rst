notegraph
=========

Note graph generator for GitHub and Jira issues.

Published docs: `inknos.github.io/notegraph <https://inknos.github.io/notegraph/>`__

``notegraph`` fetches issue and PR data from GitHub and Jira, then writes
a triplet of Logseq-compatible Markdown files: a summary page, a user
notes page, and an agent analysis page.  It also aggregates open work
into a ``worktodo.md`` page.
